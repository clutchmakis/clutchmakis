## Featured projects

### [Personal Finance CLI](https://github.com/clutchmakis/personal-finance-cli)

A tested Python and SQLite command-line application with layered domain, ledger,
persistence, and interface components. Monetary values are stored as integer cents to
avoid floating-point errors.

### [Multi-Agent Drone RL Environment](https://github.com/clutchmakis/Multi-agent-RL-env)

A PyBullet and Gymnasium multi-drone environment with dynamic waypoint allocation,
centralized PPO training, multiple assignment strategies, evaluation metrics, and a GUI
visualizer.

### [Hierarchical News Classification](https://github.com/clutchmakis/NeuroFuzzy-Project)

An NLP study comparing CNN and DistilBERT classifiers across 17 top-level categories and
109 subcategories. The recorded experiments reached 78.94% top-level and 62.87%
subcategory validation accuracy with DistilBERT.
